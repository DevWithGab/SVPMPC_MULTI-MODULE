## 🚀 Quick Start

1. **Start the server:**
   ```bash
   cd server
   npm run dev
   ```

2. **Start the client:**
   ```bash
   cd client
   npm run dev
   ```

3. **Access the app:**
   ```
   http://localhost:5173
   ```

4. **Test Super Admin:**
   - Click "Super Admin Access" at bottom of login
   - Enter password: `SuperAdmin2024!`

---

## 📝 Notes

- All passwords are case-sensitive
- Member passwords are temporary (must change on first login)
- Admin/Staff passwords are permanent
- Super Admin has access to all modules + member management
